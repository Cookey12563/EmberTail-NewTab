**Start here**

Open Ember Tail:

[<u>https://cookey12563.github.io/EmberTail-NewTab/index.html</u>](https://cookey12563.github.io/EmberTail-NewTab/index.html)

There are two separate setup tasks:

1.  Add Ember Tail as an address-bar search engine or search shortcut.

2.  Make Ember Tail appear whenever you open a new tab, where your
    browser supports it.

Doing one does not automatically do the other. A homepage, startup page,
and New Tab page are also different settings.

These instructions focus on desktop browsers. Menus can vary by browser
version, operating system, and administrator policy.

**Search-engine details**

Copy these values exactly:

Name:  
Ember Tail  
  
Shortcut / keyword:  
@ember  
  
URL with %s in place of query:  
https://cookey12563.github.io/EmberTail-NewTab/results.html?q=%s

Keep %s in the URL. The browser replaces it with your search terms.

To test the shortcut, type @ember, press Space or Tab when your browser
offers the shortcut, type a search such as cute foxes, and press Enter.

**Google Chrome**

Chrome users: you brought a whole browser to a RAM-eating competition.
Respect the commitment.

**Add Ember Tail search**

1.  Paste chrome://settings/searchEngines into the address bar and press
    Enter. Alternatively, open Settings → Search engine → Manage search
    engines and site search.

2.  Find Site search and click Add. If Ember Tail already exists, open
    its three-dot menu and choose Edit instead.

3.  Enter the name, shortcut, and search URL from the Search-engine
    details section.

4.  Save the entry.

5.  Try an @ember search.

6.  If the entry's menu offers Make default, select it if you want
    ordinary address-bar searches to use Ember Tail. Some versions may
    require activating the entry first. If your browser or administrator
    does not offer this option, use the shortcut instead.

**Use Ember Tail for new tabs**

1.  Open the Custom New Tab URL extension listing:  
    [<u>https://chromewebstore.google.com/detail/custom-new-tab-url/mmjbdbjnoablegbkcklggeknkfcjkjia</u>](https://chromewebstore.google.com/detail/custom-new-tab-url/mmjbdbjnoablegbkcklggeknkfcjkjia)

2.  Review the extension and its requested permissions, then choose Add
    to Chrome if you want to install it.

3.  Open chrome://extensions.

4.  Find Custom New Tab URL and open Details → Extension options, or use
    its Options menu if your version presents it differently.

5.  Set the new-tab URL to:  
    https://cookey12563.github.io/EmberTail-NewTab/index.html

6.  Save or apply the setting.

7.  Open a new tab to test it.

This extension is third-party software, not part of Ember Tail.
Installing it is optional. The hosted HTTPS page does not need
permission to access local file URLs.

**Opera / Opera GX**

Opera users: your browser has enough sidebars to qualify as an apartment
floor plan.

**Add Ember Tail search**

1.  Open Settings.

2.  Search the settings for Search engine and open Manage search
    engines.

3.  If an Add button is available, add the exact name, keyword, and URL
    from the Search-engine details section. If the entry already exists,
    edit it instead.

4.  Alternatively, visit Ember Tail, right-click its search field, and
    select Create Search Engine if Opera offers that option.

5.  Give it the name Ember Tail and keyword @ember, then save. If you
    used the search-field method, check the saved search URL against the
    URL above.

6.  Type @ember cute foxes in the address bar and press Enter.

Opera documents keyword-based custom searches. Do not assume a custom
entry can also become the browser's default; use @ember if that choice
is unavailable.

**New-tab setup**

Opera can install many Chrome extensions, but installation alone does
not prove that an extension can replace Opera's Speed Dial / New Tab
page.

1.  Open the Custom New Tab URL listing linked in the Chrome section.

2.  If Opera offers installation, review its permissions and install it
    only if you want to try it.

3.  Open Opera's Extensions manager and the extension's options.

4.  Enter the Ember Tail homepage URL and save.

5.  Open a new tab to test whether your version of Opera honors it.

If Opera keeps opening Speed Dial, use an Ember Tail bookmark or Speed
Dial tile instead. This README does not guarantee that Chrome's new-tab
extension will override Opera's page.

**Firefox**

Firefox users: you did not choose a browser; you adopted a fox and gave
it 37 configuration preferences.

**Add Ember Tail search**

Current Firefox versions support manually adding custom search engines.
Mozilla documents this for Firefox 140 and later.

1.  Open about:preferences#search, or open Settings → Search.

2.  Scroll to Search Shortcuts.

3.  Click Add.

4.  Enter Ember Tail as the search-engine name.

5.  Enter the search URL from the Search-engine details section.

6.  Enter @ember as the keyword, if the dialog provides that field.

7.  Click Add Engine.

8.  To make it your default, select Ember Tail under Default Search
    Engine.

9.  Test a search from the address bar.

If Add is missing, update Firefox if permitted. Older versions may
require a separate search-engine add-on; the Chrome extension below is
not a Firefox search-engine installer.

**Use Ember Tail for new tabs**

The Chrome Web Store extension is not the Firefox installation route.

1.  Visit Mozilla's official Firefox Add-ons site:
    [<u>https://addons.mozilla.org/</u>](https://addons.mozilla.org/)

2.  Search for New Tab Override.

3.  Review the listing, developer, and permissions before installing.

4.  Open about:addons and find the extension.

5.  Open its preferences or options.

6.  Enter the Ember Tail homepage URL and save.

7.  Open a new tab to test it.

Use only one new-tab replacement extension at a time to avoid conflicts.
Setting a Firefox homepage by itself does not replace the New Tab page.

**DuckDuckGo**

DuckDuckGo users: you ducked the trackers so hard you also ducked half
the customization menu.

DuckDuckGo Search and the DuckDuckGo browser are different products.

**If DuckDuckGo is your search engine in another browser**

Follow the instructions for the browser you actually use: Chrome, Opera,
Firefox, or Edge. Changing the search-engine entry is handled by that
browser, not by the DuckDuckGo website.

**If you use the DuckDuckGo browser**

Do not assume it accepts Chrome extensions or the same custom
search-engine settings. This README does not provide a verified
custom-engine or New Tab override procedure for the DuckDuckGo browser.

The practical fallback is:

1.  Open the Ember Tail homepage.

2.  Add it to your bookmarks or favorites using the browser's menu.

3.  Name the bookmark Ember Tail.

4.  Open it whenever you want to use Ember Tail.

5.  Search using Ember Tail's page rather than expecting @ember to work
    in the browser's address bar.

If your version offers a custom homepage or startup URL, you can use the
Ember Tail homepage there. That still does not necessarily change every
new tab.

**Bing / Microsoft Edge**

B-b-b-b-Bing users: your search engine showed up dressed like a
rewards-program pop-up. We can still help you escape politely.

Bing is a search engine, not a desktop browser. If you use Bing in
Chrome, Firefox, or Opera, follow that browser's instructions. If you
mean Microsoft Edge, use the steps below. These are not instructions for
the Bing mobile app.

**Add Ember Tail search in Edge**

1.  Open Edge Settings.

2.  Navigate to Privacy, search, and services → Search and connected
    services → Address bar and search. Menu labels may vary slightly.

3.  Open Manage search engines if available.

4.  Choose Add, or edit an existing Ember Tail entry.

5.  Enter the name, keyword, and URL from the Search-engine details
    section.

6.  Save it.

7.  If the entry offers Make default, select that if desired. Otherwise,
    use the @ember shortcut.

8.  Test an address-bar search.

Edge can also discover supported search engines after you use them, but
do not rely on automatic discovery for Ember Tail unless it appears in
your settings.

**New-tab setup in Edge**

1.  Open the Custom New Tab URL listing linked in the Chrome section.

2.  If Edge offers installation from the Chrome Web Store, allow that
    store only if you are comfortable doing so, review the permissions,
    and install the extension.

3.  Open Edge's Extensions manager and the extension's options.

4.  Enter the Ember Tail homepage URL and save.

5.  If Edge asks whether to keep the extension's new-tab change, approve
    it only if that is what you want.

6.  Open a new tab to test it.

Availability depends on your Edge version and policies. If the
installation or new-tab change is unavailable, bookmark Ember Tail
instead.

**Add your own background.png**

For a personal copy of the site:

1.  Fork or download the EmberTail-NewTab project.

2.  Choose an image you own or have permission to use.

3.  Export it as a real PNG image. Renaming a JPG to .png does not
    convert it.

4.  Name it exactly background.png, using lowercase letters.

5.  Replace the existing background image at the location the site's
    HTML or CSS references. If that reference is simply background.png,
    place it alongside the page that resolves that path. If the code
    references another folder or filename, match that path or update the
    reference.

6.  Commit the change and deploy your personal copy if you are hosting
    it.

7.  Reload your copy of Ember Tail. If the old background remains, try a
    hard refresh.

8.  If you host your own copy, change your new-tab extension's URL to
    your homepage and change your custom search URL to your hosted
    results.html?q=%s address.

A file on your computer does not change the public Cookey12563 GitHub
Pages site. These steps customize your own copy. Automatic background
loading depends on the site's existing HTML/CSS pointing to that image;
this README does not add that code.

**If your administrator blocks the extension**

If you see:

Your admin has blocked this item  
(ID: mmjbdbjnoablegbkcklggeknkfcjkjia)

1.  Do not try to bypass your school or workplace's browser policy.

2.  Ask the administrator whether they can approve the extension or
    configure the new-tab page for you.

3.  In the meantime, bookmark the Ember Tail homepage.

4.  Keep using the Ember Tail search shortcut if your policy allows it.

An extension block does not by itself mean the Ember Tail website is
broken. Address-bar search, bookmarks, and new-tab replacement are
separate features and can have separate restrictions.
